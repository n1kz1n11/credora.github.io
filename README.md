# Credora

Статическая финансовая витрина на Astro, TypeScript и обычном CSS.

## Запуск

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Production-сборка:

```bash
pnpm build
```

## Данные предложений

- Займы: `src/data/loans.ts`
- Банковские карты: `src/data/cards.ts`

CTA ведёт напрямую на `partnerUrl`, заданный в данных продукта. Если ссылка не предоставлена, карточка безопасно показывает неактивную кнопку.

## Яндекс Метрика

Передайте реальный ID через переменную `PUBLIC_YANDEX_METRIKA_ID`. Без неё код Метрики не загружается. Для активных партнёрских ссылок отправляется цель `partner_click` с ID, названием, категорией и позицией продукта.

## Домен и SEO

Перед публикацией передайте абсолютный HTTPS-адрес сайта через `PUBLIC_SITE_URL`, например `https://example.ru`. Пока переменная не задана, сайт не генерирует canonical и Open Graph URL, а sitemap остаётся без адресов — это исключает публикацию выдуманного домена. После настройки `/robots.txt` автоматически укажет на `/sitemap.xml`.

Шаблон переменных находится в `.env.example`.

## Перед публикацией

1. Задайте `PUBLIC_SITE_URL`; `/robots.txt` и `/sitemap.xml` автоматически получат абсолютный адрес.
2. Заполните сведения о владельце/операторе и даты редакций в юридических документах.
3. Добавьте отсутствующую партнёрскую ссылку Фора-Банка и проверьте актуальность условий.
